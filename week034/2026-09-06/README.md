추가로 AI에게 전공 이외의 질문을 할 경우 영어로 질문하는 습관을 들여 영어 말하기 및 쓰기 실력도 같이 키울 예정이다.

작성 모듈같은 경우가 상당히 까다로울 것이라고 생각하고 지금까지 주석을 달아둔 부분을 활용해 코너 케이스가 생기는 일이 없도록 여러 번 체크할 필요가 있을 것 같다.
