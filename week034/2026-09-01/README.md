4. UART 프로젝트 UARTTCR레지스터 동작 분석 및 설계

UART 프로젝트를 진행하던 중 UARTTCR의 TESTFIFO가 1로 세트된 경우 RX_FIFO에 직접 쓰거나 TX_FIFO에서 직접 읽어올 수 있는 기능이 있음을 발견하고 원래 UARTCLK에서 
하던 동작을 PCLK에 맞추어 동작할 수 있도록 해야 하는 구조를 만들어야 함을 발견했음. 기존 mode 멀티비트를 전달하기 위해 사용한 MCP + 펜딩 레지스터 구조로는 데이터가
손실돼지 않게 할 수 없음을 발견했고 FIFO_FULL/EMPTY 플래그를 SW 폴링 신호로 사용하고 기존 MCP + req/ack 구조는 그대로 재사용하기로 결정했음. 내일 시간이 남을 때
구체적인 설계방식을 구상한 후 추가할 예정임
