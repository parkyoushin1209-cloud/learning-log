느낀점
전기회로에서 처음에는 다소 모호하고 어렵게 느껴지는 개념들이었으나 문제를 풀면서 하루만에 어느정도 문제까지는 풀 수 있게되었다. 아직 풀지 못한 문제가 많이 있어 앞으로
중간고사 전까지 각 단원마다 문제를 풀며 매일매일 조금씩 문제를 풀 생각이고 내일은 아침에만 잠깐 이산 수학 공부(여러가지 용어들의 정의 및 이외의 내용)를 진행할 생각이고
오후에는 레포트 작성을 마친 뒤 화요일부터는 다시 SVA 및 SV 학습을 진행할 수 있을 것 같다. 공학 수학, 전기회로의 경우는 문제를 풀면서 익히는 방법밖에 없을 것 같아 공학
수학도 매일 몇 문제씩이라도 풀 생각이다.
