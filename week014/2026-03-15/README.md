느낀점
실험 장치 메뉴얼로는 실험 장치 사용법을 잘 모르겠어서 여러 영샹을 찾아보고 검색해보느라 시간이 좀 걸렸지만 이후에도 써먹을 수 있을 것이라 생각하고 또 내일 실험도 빨리 끝낼 수 있지 않을까 하는 기대감도 있어서 크게 문제로 삼을만한 내용은 아니었던 것 같다. 또한 SVA를 통해 그동안 궁금했던 검증 지시어들의 역할을 확인하고 각각의 지시어들을 언제 사용하는 지 알 수 있었던 점이 좋았다. 처음에는 막상 모호하게 느껴지는 부분들이 많았으나 코드와 ai에게 질문함으로써 비교적 많이 명확해졌다고 생각한다.
또한 커버리지에 대해 공부하면서 LRM을 통해 커버리지 옵션이나 제약 bins에 대해 추가로 학습할 필요성을 느꼈고 추후에 학습할 예정이다.
