느낀점
전기회로의 경우 많이 막막해 보이던 회로를 다른 회로로 바꾸는 과정에서 흥미를 느낄 수 있었고 잘 안 풀리던 문제를 해결해 나갈 수 있었던 점이 좋았다. SVA의 어써션 샘플링같은 경우에는 이전에 나왔던 내용에서 조금만 더 추가된 느낌이라 어렵지 않게 받아들일 수 있었지만 아직 $past 등의 샘플링 값 함수랑 triggered, matched 등이 함께 쓰인 경우에 대해서는 모호한 부분이 있어서 나중에 직접 겪으면서 이해하는 게 좋을 것 같다.
