1. 프로비니우스 해법 개념 학습 및 연습

y = am* x^(m+r)로 두고 풀이 시작 a0가 0이 되지 않도록 하는 r이 결정 방정식의 해가 됨
x^2y`` + xb(x)y` + c(x) = 0에서 r(r-1)+b0 *r + c0 =0이 결정 방정식으로 b0, c0는 b, c 함수에 x=0을 대입한 값임

느낀점
프로비니우스 해법을 사용해 문제를 풀 경우 이전에 배운 내용들로는 풀기 어려운 문제라도 이 해법을 사용해서 풀 수 있었다. 그러나 시간이 매우 오래 걸리며 풀이 과정도
복잡한 내용들이 많아 주의해서 풀 필요가 있겠다고 생각했다. 또한 시그마를 조작하는 방법 여러 가지 경우에 대해 팩토리얼로 나타내는 연습 등 여러가지를 배울 수 있었다.
