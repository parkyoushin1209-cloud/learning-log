>> 연산자의 경우 주어진 타입의 표준 형식에 따라 그 타입의 객체에 값을 읽는다.
(int일 경우 숫자가 아닌 문자를 마주칠 때까지 읽고 string의 경우 공백 문자가 나올 때까지 읽음)

cin.get(ch)는 한 문자씩 읽으며
getline(cin, str)는 한 행씩 읽는다. 스트림의 상태도 확인 가능하다.

문자 분류 라이브러리 함수로는 다음의 것들이 있다.( ||로 조합 가능하다.)
  isspace(c): c가 공백문자인가?
  isalpha(c): c가 알파벳인가?
  isdigit(c): c가 10진 숫자인가(0~9)?
  isxdigit(c): c가 16진 숫자인가 (0~9, a~f, A~F)
  isupper(c): c가 대문자인가?
  islower(c): c가 소문자인가?
  isalnum(c): 알파벳 또는 10진 숫자?
  iscntrl(c): 제어문자?
  ispunct(c): 알파벳, 10진 숫자, 공백 문자, 보이지 않는 제어 문자 중 어디에도 속하지 않는가?
  isprint(c): 출력 가능 문자인가(아스키 문자표에 있는가?)
  isgraph(c): isalpha, isdigit, ispunct중 참인게 있는가?

대/소문자 변환
  toupper(c)
  tolower(c)

문자열 소문자로 변환하는 코드
void tolower(string& s) { //참조로 전달
	for (char& x : s) x = tolower(x); //소문자로 변환하기
}
