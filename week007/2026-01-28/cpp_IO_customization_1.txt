정수 출력(16진수:hex 8진수:oct 10진수: dec[기본])으로 출력 가능 
cout << oct << value; 처럼 // dec, hex, oct 등을 조정자라 함
cout << showbase << 조정자 (이 형식에 맞춰출력됨 접두사는(10진수: 없음 16진수: 0x, 8진수:0임) 기본적으로 다른 진수로 입력해도 출력은 showbase에 맞춤
noshowbase 접두사 없음

정수 입력 >>는 기본적으로 숫자가 10진수라고 가정 cin >> vala >> hex >> valb >> oct >> valc >> vald 영속적이므로 valc와 vald는 모두 8진수로 출력

cin.unserf(ios::dec);//0x를 16진수로 해석할 수 있게)10진수 가정 안함
cin.unsetf(ios::oct);//12를 십이로 해석할 수 있게 8진수 가정 안함
cin.unsetf(ios::hex);//12를 심이로 해석할 수 있게 16진수 가정 안함
=> 모든 기본 설정 해제 연산자가 0, 0x등의 접두사를 읽어 올바르게 해석 가능함
//unsetf는 인자로 지정한 플래그를 해제한다.

  부동소수점 출력
  fixed: 고정소수점 표현
scientific: 가수와 지수 표현, 기수는 항상 [1:10] 구간에 있음, 소수점 앞 0이 아닌 자리 수 1개 존재
defaultfloat: defaultfloat의 정밀도 안에서 fixed, scientific 중 더 정확한 표현을 선택

정밀도
setprecision(n)으로 
defaultfloat은 전체 자리수를 n자리로
scientific은 소수점 이후 자리 수 n자리
fixed 소수점 이후 자리 수 n 자리

필드 
setw(n) 필드 너비 지정자
필드 너비는 영속적이지 않다. n이 유효숫자보다 작으면 무시된다.

파일 스트림 열기 모드
ios_base::app : 덧붙이기(파일 끝에 추가)
ios_base::ate: "끝에서"(파일을 열고 끝으로 이동)
ios_base::binary: 바이너리 모드(시스템에 따라 동작이 다름)
ios_base::in/out : 읽기/쓰기 모드
ios_base::trunc : 파일 길이를 0으로 절삭

바이너리 파일
기본적인 istream, ostream과는 달리 문자열이 아닌 바이트 단위로 읽고 씀
binary 지정 시 바이트를 조작하지 않음 = 중간에 변환이나 해석을 하지 않고 그대로 저장 읽음
바이너리 입출력의 코드는 지저분하고 복잡하며 오류 발생 가능성이 높다
문자 입출력:이식성이 높고 사람이 읽기 쉬우며 시스템에 의해 뒷받침 됨

파일 안에서의 위치 지정
가능하면 파일의 처음에서 끝까지 차례대로 접근하는게 가장 쉽고 오류 적음
파일을 변경해야하는 경우에도 변경된 내용을 포함하는 새로운 파일 만들기를 권장함
읽기용으로 연 파일에는 읽기 위치(get/read position) 존재 쓰기용으로 연 파일에는 쓰기 위치(write/put position)존재
