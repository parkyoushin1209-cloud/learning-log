느낀점

걱정이 좀 됐었는데 지금은 이 책을 읽어나가는 과정이 재밌다. 앞으로 빠르게 다 읽은 뒤 베릴로그랑 통합해서 정리해준 뒤 여러가지 코드를 짜보고 싶다. 코드를 짜는 과정을 조금 가진
뒤 다시 UVM을 목표로 공부해나갈 생각이다. 아직 절반 조금 넘게 읽은 게 다지만 앞으로도 이대로 계속 해나가면 될 거라고 생각한다.
