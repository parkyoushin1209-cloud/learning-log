오늘부로 모든 스펙 분석 및 RTL 작성 TB 작성 RAL 작성 등 여러가지 작업을 마무리했고 내일 하루동안 그동안의 과정을 보고서로 정리함으로써 다음 프로젝트인 UART로 넘어갈
생각이다. 이번 프로젝트를 하면서 디버깅에 사용하면 좋을 방법을 여러가지 새롭게 알 수 있었고, always_comb 및 always_ff의 평가 방식 또한 clocking 블록 input, output
지연의 정확한 의미 등을 알 수 있게 되었고 델타 사이클을 포함한 이벤트 스케쥴링에 대해 좀 더 자세히 알 수 있개 되었다. 2학기 초반까지 UART 프로젝트 마무리를 목표로 할
것이며 2학년 겨울 방학 초까지는 하드웨어 타이머 검증 마무리, 이후 AHB, AXI 등등 더 어려운 프로토콜을 이용하는 Peripheral 검증까지 이어나갈 생각이다.
