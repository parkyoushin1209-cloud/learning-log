디버깅 작업 중 mismatch를 9개 정도까지 줄이기는 했으나 남은 에러의 원인을 아직 찾아내지 못해 계속해서 디버깅 작업을 진행해야 할 것 같다. 저장된 레지스터 값을 통해
예상값을 계산하는 로직 자체에는 문제가 없는 것으로 추정하고 있으며 DUT에서 알 수 없는 이유로 GPIN이 대입되는 assign 문에서 z가 할당되는 것인지 모든 mismatch에서
GPIN으로 인해 발생한 문제만 있었으며 내일 디버깅 중 이에 대한 원인을 찾아내고 수정해야 할 것 같다.
