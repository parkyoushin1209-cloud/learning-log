 느낀점
 다행히 오늘 이산 수학 시험을 잘 볼 수 있었던 것 같다. 앞으로도 모든 시험을 잘 볼 수 있을 것 같다는 느낌도 받아서 다행이었다. 앞으로도 꾸준히 학습하는 것이 중요하겠다고
 생각했고 이번주 모든 시험을 무사히 마치고 다시 시스템 베릴로그와 전자장 학습에 몰두할 수 있도록 준비도 잘 하는게 중요하다고 생각한다. 여러가지 학습 내용을 바꿔가면서 
 공부하는 것에도 관성이 있는 것 같아서 이런 환경에 적응할 수 있도록 신경 써야겠다.
