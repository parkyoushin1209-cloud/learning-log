1. 체커 관련 내용 학습

체커는 프로그램, 인터페이스, 모듈로 바인드 가능함
체커는 모듈, 프로그램들과 달리 절차적으로 인스턴스화도 가능함
체커내 정적 어써션, 체커 절차 외부 인스턴스화 -> 인 블록 
체커내 정적 어써션, 체커 절차 내부 인스턴스화 -> 인라인
체커내 절차적 어써션, 체커 절차 외부 인스턴스화 -> 인블록
체커내 절차적 어써션, 체커 절차 내부 인스턴스화 -> 외부 프로시저 블록으로 나가서 인블록 처럼 동작함

체커에는 always가 올 수 없음, 자동 변수 불가, 테스크 불가 등등 테블릿 정리 확인
