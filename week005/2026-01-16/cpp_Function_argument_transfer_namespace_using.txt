함수매개변수 전달
1. 값에 의한 전달: 값을 복사해 함수로 전달, 매우 작은 객체를 전달할 경우
2. 상수 참조에 의한 전달: const vector <double>& v 형태로 넘겨줌, 객체 수정은 불가능, 수정할 필요가 없는 큰 객체 전달할 경우/참조인자를 읽기로
3. 참조에 의한 전달: int&r 형태, 꼭 필요할 때만 사용하기, 컨테이너를 비롯한 큰 객체 조작, 함수 안에서 여러 객체 변경 시

void g(int a, int&r, const int&cr){
++a;// 지역 변수 변경
++r;//r이 가리키는 객체 변경
int x = cr;//cr이 가리키는 객체 읽기
}
g(1,2,3) => error, r은 변수여야함
g(1,y,3) => 컴파일러가 cr이 가리킬 임시 객체를 생성해줌

함수 호출시 함수의 모든 매개변수의 사본, 지역 변수를 포함하는 자료구조인 함수 활동 기록을 할당함
호출 스택에 후입 선출 방식으로 늘었다 줄었다를 반복함

컴파일러에 의한 함수 계산 => constexpr 함수 선언 -> 인자가 상수 표현식이어야 함
-함수에 반환문이 단 하나, 함수의 반환값 대입, 이를 이용해 초기화 하는 변수 제외 함수 몸체 외부 변수를 변경하면 안됨
int glob = 9;
constexpr void bad(int&arg){//return문이 없음
++arg;//호출하는 쪽 상태를 변경합
glob = n;//비 지역 변수를 변경함
}=> error
평가순서는 코드 순 소멸은 반대 순
한 표현식에서 변수 값 변경 시 동일한 표현식에서 변수 재사용 금지 ex. v[i] = ++i, int x = ++i + ++i 등 => 모든 컴퓨터에서 동일한 결과 보장x, =의 경우 오른쪽이 먼저 계산된다는 보장x

네임스페이스명 :: 멤버이름(완전 한정 이름)으로 접근하며 추가적으로 멤버이름과 동일한 전역 변수 사용 가능함
using은 std :: string을 string만으로 이용 가능하게 하며 주로 std에만 사용함 다른 네임스페이스에 사용시 name conflict 발생확률 올라감
