느낀점
공학 수학같은 경우 문제를 풀 때 계산량이 너무나도 많아진 느낌이어서 하루만에 다 끝내기에는 무리가 있는 것 같아 매일 조금씩 나눠서 풀어야 할 것 같다고 생각했고 
전기회로의 경우 이전에 어렵게 느껴지던 부분 특히 저항들이 매우 복잡하게 얽혀있는 회로에서의 등가 저항을 찾는 문제에 대해 접근법을 찾아내서 이제는 잘 해결할 수 있을것
같다. 객체지향 프로그래밍의 경우 개념만 좀 더 확실하게 보완하면 될 듯하고 다다음주가 시험인만큼 더 체계적으로 준비할 필요가 있을 듯하다.
