느낀점
테스트벤치를 직접 작성하면서 단순히 내용만 암기할때는 생각지도 못했던 질문들이 떠올라 이에 대해 찾아볼 수 있었고 확실히 능동적인 학습 및 실전 연습이 중요하다고 생각했다.
또한 앞으로 중간고사까지 얼마 안 남았다고 판단해 당분간은 학교 공부 비중을 높일 필요가 있을 것 같다고 생각해 그에 맞게 학습 계획을 세울 것이다. 이때는 학교 공부를
메인으로 잡고 그동안 정리했던 내용을 조금씩 복습하는 식으로 망각하지 않도록 노력할 것이다.
