느낀점
EDA Playground로 완변학 커버리지 리포트를 볼 수는 없더라도 여러 메서드를 통해 커버리지를 측정하는 연습 및 예시 코드를 이용한 테스트벤치 작성까지 매일 조금씩 해나가며 
코딩에도 비중을 두면서 공부하면 좋을 것 같다. 다행히 자바에서도 크게 다른 문법이 없어서 어렵지 않게 배울 수 있는 것 같고 전기회로 관련해서도 회로를 구성해보고 시뮬레이션
을 돌려보는 과정이 흥미로웠고 앞으로도 유용하게 사용할 수 있을 것 같다. 앞으로 여러가지 코드를 확인 후 제약, 어써션, 커버그룹 작성 등 여러가지를 해보며 여러 가지 기술을
익히고싶다.
