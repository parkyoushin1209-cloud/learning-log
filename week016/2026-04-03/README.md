느낀점
자바의 경우 분량이 상당히 많았지만 그동안 OOP를 어느정도 배워둔 것들이 있어서 쉽게 학습할 수 있었지만 공학 수학에서 수식이 굉장히 많기도 하고 물리학이랑 연결되다보니
어려운 내용도 있었지만 비제차 2계 선형 상미분방정식을 푸는 방식으로 미정 계수법, 매개변수변환법을 학습하고나서 물리학 관련 공식을 외울 필요 없이 식을 유도할 수 있게
되었다. 물론 외울 필요도 있겠지만 아직은 풀이법을 익히는게 좋을 것 같다. 다른 과목들의 경우 아직 시작도 못해서 토요일, 일요일을 활용해 완전히 학습할 수 있도록 할 
생각이다.
