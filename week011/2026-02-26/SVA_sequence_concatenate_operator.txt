[*0:m] 반복 범위
0번(skip) ~ m번까지 반복되야함
degenerate(축퇴) = no_match, empty_match만 가짐 // empty 매치는 반복횟수가 0인 것을 의미 [*0] 또는 ##0 등(ex. a[*0] ##0 b)
nondegenerate(비축퇴) = 최소한 1개의 non empty match를 가져야 함
프로퍼티로 쓰이는 시퀀스는 nondegenerate여야 함**

goto 반복 
시퀀스는 안되고 부울식만 가능
b[->m] = (!b[*0:$] ##1 b)[*m] // first match는 불필요 b가 m번 나타나면 매치되는 스레드는 한 개뿐임
가이드라인***
1. 고투 반복 연산자를 가지는 선행조건 시퀀스가 멀티스레드를 가지지 않는 한 first match 사용하지 말기
2. 선행조건의 첫 항에 고투 연산자 사용을 피하기 // 값이 맞지 않더라도 공허한 어써션이 만들어지는 것이 아닌평가가 시작돼 계산량 많아짐
3. 절대 실패할 수 없는 후속조건을 피하고 실패 가능한 스타일로 재작성 고려
-> [0:$] b ##1 c 대신 ->[b->1] ##1 c로
4. 후속조건이 안 끝날 것 같다 => strong 사용

반복수는 고정상수 또는 고정 범위
b[=m]  == (b[->m] ##1 !b[*0:$]) // m+1 반복은 안됨

2. 선행조건 첫 항에 불연속 반복 연산자가 있는 시퀀스 사용 피하기
//공허한 어써션 대시 새로운 시도 생성 가능 => 커버리지 전략을 덜 의미 있고 추적에 큰 오버헤드가 될 수 있음

시퀀스 구성 연산자 => 시퀀스 결합, 작성성/가독성 향상, 관계 표시 가능
1. ## 시퀀스 연결
##0(시퀀스 오버래핑 연결)
두 시퀀스를 한 사이클 안에서 연결
##[1:$] 대신 goto 사용 고려

시퀀스가 부울식이면 &&을 사용해도 기능은 같으나 &&는 조합 논리 추론을 가지는 반면 ##0은 순차적 추론을 가짐
빈 시퀀스와 혼합된 시퀀스는 빈 시퀀스임
오버랩 매치는 두 시퀀스가 최소 한 사이클 이상 겹치면서 매치되는 지점이 있어야 가능(두 시퀀스중 하나만 empty여도 불가능) ***
empty ##0 seq = no match
empty ##n seq = ##(n-1) seq
seq ##0 empty = no match
seq ##n empty = seq ##(n-1) true

시퀀스 분리(OR)
각각의 시퀀스의 첫 클럭킹 이벤트에서 시작 같이 끝날 필요 없음
한 시퀀스만 참이어도 참
그 시퀀스가 프로퍼티로 쓰인다면 no match는 어써션 실패를 의미

시퀀스 non-length-matching (and)
각각의 시퀀스의 첫 클럭킹이베느에서 시작 같이 끝날 필요 없음
두 시퀀스가 모두 참이면 참(마지막 시퀀스가 참이 되는 시점에 어써션도 참)

시퀀스 length-matchin(intersect)
시작/종료지점 동일
멀티스레드 시퀀스일 경우 같은 시작/종료 지점을 가지며 매치되는 RHS, LHS를 탐색함
실패하기 위해서는 모든 매칭 조합중 하나라도 유효한게 없어야 함
성공하려면 매칭되는 끝점에서 실패하지 않아야 함// 하나라도 성공하면 어써션은 성공

규칙 클럭 플로우는 intersect의  RHS 변경 불가
assert property(@(posedge clk) e |-> (a ##1 b) intersect (@(posedge clk2) c ##1 d)); // 불법임

assert property(@(posedge clk) e |-> (a ##1 b) intersect (e ##1 @(posedge clk2) c ##1 @(posege clk)d)); // 후속의 RHS, LHS가 같은 leading clk event를 가지며 같은 clk event에서 끝나므로 ok
[=],[->]를 intersect와 함께 사용하면 경계를 줌
a[=2] intersect b[*5] // 5사이클 안에 a가 2번 나와야함

시퀀스 포함(within)
seq1 with seq2의 매치는 다음을 반드시 만족함
seq1의 시작이 seq2의 시작보다 느리고
seq1의 종료는 seq2의 종료보다 빠르다
제한 범위를 줄 때도 사용 가능 ~~within 1'b1[*1:256]

시퀀스동안 표현식(throughout 연산자)
신호(표현식)이 시퀀스동안 반드시 지켜져야 함
b throughout R = b[*0:$] intersect R
우측이 지켜지지 않으면 no match // ex. a throughout b[*3]

 PWAKEUP |-> ##[2:$] PSELx
PWAKEUP이 PSELx 최소 두 사이클 전에 나타나야함 =>  함축 연산자 + 최소지연 활용
