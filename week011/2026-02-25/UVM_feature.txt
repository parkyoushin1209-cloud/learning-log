UVM : 효율적이고 철저한 검증을 위해 최고의 실용적인 것들을 법문화한 완전한 방법론
핵심 원칙 = 발전 + 재사용성 강화

UVM의 핵심 특징
- 데이터 디자인
검증 환경을 구체적 데이터 아이템 + 컴포넌트 집합으로 명확히 구획할 능력 제공
글자로 출력, 그래프로 객체 뷰잉, 계층적으로 객체 내 데이터 값 설정/획득 등 활동 간단화
복사, 비교, 아이템 패킹 등 평범한 활동을 자동화할 내장된 능력 제공
=> 엔지니어가 객체가 포함할 것, 어떻게 동작할지에 집중 가능

-스티뮬러스 생성
연속적 데이터 흐름의 미세 조정이 가능하도록 클래스와 기반 구조 제공
사용자가 DUT의 상태, 인터페이스, 미리 생성된 데이터를 포함한 환경의 현재 상태에 기반해 데이터 랜덤화 가능
사용자 정의 계층적 트랜잭션과 트랜잭션 흐름 생성을 포함하도록 커스터마이즈 가능한 스티뮬러스 생성 메커니즘 제공

-테스트 벤치 제작 및 실행
테스트벤치 생성은 갈수록 어려워짐
UVM 기반 클래스는 UVM의 효율적 사용을 돕고 자동화를 제공
설정 인터페이스는 런타임 행동, 구현 변경 없이 테스트벤치 토폴로지 커스터마이즈를 가능하게 해 재사용성을 높임

-커버리지 모델 디자인 및 검사 전략
기능적 커버리지, 물리적/일시적 프로토콜, 데이터 검사를 재사용 가능한 UVC로 통합하게 해줌

-빌트인 분석 및 디버그 능력
라이브러리, 방법론은 일관되고 유익할 에러 메세지 보고, 트랙잭션 로깅, 시퀀스 추적, 더 많은 것들을 위한 메커니즘 제공

- 유저 예시
이해하기 쉬운 아직 미완료된 XBus라 불리는 프로토콜 기반 골든 시스템 베릴로그 예시를 포함함
이 예는 방법론, 기반 클래스를 사용한 테스트, 시퀀스, 테스트벤치 구조, 파생된 UVC를 포함함



랜덤 스티뮬러스를 포함하는 검증 환경 개발 시 다음을 고려해야 함
1. 적용된 자극의 결과가 올바른지 알기 위해 셀프 체킹 테스트벤치 사용 필요
2. 생성한 스티뮬러스 추적(기능적 커버리지 이용)              => 무엇이 검증되었는가와 설계가 올바른지에 대한 이해도를 올려줌

UVM은 metric-driven verification(MDV) 를 달성하기 위한 최고의 프레임워크를 제공함
MDV는 자동 테스트 생성, 셀프 체킹, 커버리지 메트릭스를 결합해 검증시간을 줄이며 목표는 다음과 같음
1. 초기에 목표 설정 후 이를 기반으로 검증
2. 수동으로 수 많은 테스트를 생성하는 데 걸리는 시간 줄임
3. 에러 분석, 디버깅을 간단히하고 에러 통지를 가능한 빨리 얻기 위해 런타임 셀프 체킹 사용

UVC 인터페이스의 기본 타입
1. point to point UVC 단일 마스터(트랜스미터), 단일 슬레이브(리시버)를 가지고
2. BUS UVC : 여러 마스터, 슬레이브, 선택적으로 버스 모니터, 중재자를 가질 수 있음
UVC 인터페이스는 다른 인터페이스 사이에 데이터, 시간 동기화 / 특정 테스트를 위해 테스트환경을 미세하게 컨트롤하게 해줌

UVC 모듈
서브 시스템 또는 단일 모듈에 대한 검증 로직 포함함
거대한 시스템의 서브 시스템 검증을 가능하게 함
보통 스코어 보드, 블록 레벨 기증적 커버리지를 포함할 것
