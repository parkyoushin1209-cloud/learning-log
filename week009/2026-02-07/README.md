느낀점
verilog의 15장은 검증 과정 관련한 내용이었다. 이 내용은 이전에 systemverilog for verification이라는 책을 읽기 전에는 이해가 되지 않는 내용 단순히 암기해야 하는 내요잉 많았다고 생각했
었는데 읽고 난 후 다시 보니 단순히 문장만 본다기보다는 "아 이런 내용은 어떤 내용을 말하고 있는 거겠네" 이런 느낌을 받으며 읽을 수 있었고 시스템 베릴로그의 경우 한 번에 읽고 나중에 정리
한다기보다는 한 챕터를 읽고 다시 복기해보고 마지막 깃허브 정리할 때 한 번 더 정리해보는 과정에서 단순히 잃어버리는 내용보다는 기억에 남게되는 내용들이 더 많다고 느꼈다. 또한 AI로 인해
많은 일자리가 사라질 수도 있는 세상에서 검증 엔지니어의 일은 이 시스템을 어떻게 망칠 수 있을까를 끊임없이 고민해보고 케이스를 적용해 보는 것이고 이는 AI에 있어서도 적용 가능할 거라고
생각했다. 따라서 검증 엔지니어라는 목표를 더욱 확고히 할 수 있을 것 같다고 생각했고 시간이 남는다면 AI에 대한 공부도 해보는 것도 좋을 것 같다고 생각했다.
