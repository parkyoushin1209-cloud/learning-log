203일차 학습한 내용
1. GPIO spec 확인을 통한 DUT RTL 수정
2. 스코어보드 참조 모델 생성
3. GPIO 내부신호 생성

Primecell GPIO spec 분석 중 하드웨어 제어 모드일 때 GPIODATA의 액세스 메커니즘에 대한 오해를 발견하고 RTL을 일부 수정하고 스코어보드 내 참조 모델을 만들었다.
내일 GPIO io Transaction을 만들고 스코어보드에서 예상치를 생성하는 참조모델과 실제 값을 비교하는 메커니즘을 생성할 예정이다. 별다른 문제가 없을 경우 내일 TB 생성을
마무리하고 이후 어써션 작성 및 체커 바인드 작업까지 마무리 한 후 테스트 시퀀스를 생성해 디버깅해 나갈 생각이다.
