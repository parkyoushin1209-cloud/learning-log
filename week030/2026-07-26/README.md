206일차 학습한 내용
1. 파이썬 엑셀 다루기(1) 학습
2. 테스트 시퀀스 작성 및 디버깅 작업 1일차
3. 파이썬 정규 표현식 다듬기

파이썬으로 파일 다루기를 마무리하고 엑셀 다루기 학습을 시작했으며 추가적으로 테스트 시퀀스를 가볍게 하나 작성하고 오타 및 문법 오류같은 에러를
찾아서 수정하고 있다. 파이썬 정규표현식을 사용해 에러 문장만 뽑아내며 느꼈던 점은 EDA playground 로그 자체로는 매우 지저분해보이나 에러 문장만
잡아내 수정해야할 부분만 빠르고 덜 지저분하게 볼 수 있었어서 매우 편리했다는 점이다. 내일부터는 파이썬은 하루에 1~2챕터씩만 보는 것을 목표로 하고
추가로 디버깅 작업을 계속하면서 에러 문장별로 무엇이 문제 였는지 적어두는 작업을 진행할 것이며 빠르면 이번달 내로 프로젝트를 마무리하고 늦어도
다음달 1번째 주까지 프로젝트를 마무리 하는 것을 목표로 할 것이다.
