1. 파이썬 설치 및 AUTOMATE THE BORING STUFF WITH PYTHON 1~6장 학습

현재 진행중인 GPIO 프로젝트의 경우 테스트 시퀀스만 작성하고 디버깅하는 작업만 마무리 하면 되는 상태까지 왔다. 그러나 앞으로도 파이썬을 통한 로그 분석 자동화가 필요한
만큼 테스트 시퀀스 작성에 앞서 새로 구매한 책을 통해 파이썬을 어느정도 배우고 이를 디버깅에 이용해보면 좋을 것 같다고 생각해 파이썬을 미리 학습하기로 했고
빠르면 내일 내로 필요한 부분을 전부 학습하고 로그 분석에 이용할 수 있을 것이라고 생각하며 늦어도 일요일까지는 마무리 할 생각이다. 로그 분석 및 커버리지 홀 채우기까지
마무리한 후 프로젝트 과정을 총정리해 깃허브에 정리함으로써 GPIO 프로젝트를 마무리 할 예정이며 이후 바로 UART spec 분석으로 다음 프로젝트를 진행할 생각이다.
