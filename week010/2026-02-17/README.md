느낀점
테스트벤치를 작성할 때 alu의 경우 컴포넌트들을 어떻게 작성해야할 지 어느정도 알게 된 것 같으나 아직 다른 모듈들은 해본 적이 없어서 앞으로 2일정도는 모듈을 찾아보고 테스트벤치를 작성해볼 생각이다. 또한 아직 DUT, 인터페이스, clk 연결이 아직 많이 미숙하다고 생각해 이 세가지를 연결하는 부분만 따로 떼어내 연결하는 방법도 계속 생각해볼 것이다. 아쉽게도 배송 날짜가 2주 이상 밀려버려서 남은 어써션을 먼저 공부하게 될 듯하다. 앞으로 몇일동안은 다시 c++에도 집중하며 c++분량도 더 많이 늘려볼 생각이다.
