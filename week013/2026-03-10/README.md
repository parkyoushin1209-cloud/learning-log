느낀점
오늘 fifo 검증 환경을 구축하면서 이전에 해봤던 것들 말고 추가로 클럭킹 블록에 프로퍼티 추가 후 되서는 안 될만한 조건을 생각해 어써션을 작성하는 연습을 해봤다. fifo 같이 간단한 케이스라서 그런지 모르겠지만 어써션 작성에 있어서 크게 어렵게 느껴지는 점들은 없었고 앞으로는 어써션 작성도 물론 중요하겠지만 어떤 부분을 어써션으로 잡을지 구상하는 연습을 해보는 것도 중요하겠다고 생각했다. 그리고 이론 위주의 학습도 물론 중요하겠지만 이론은
2학년 때 최대한 마무리하는 연습을 한 뒤 3,4 학년은 검증 프로젝트를 만드는 것에 좀 더 비중을 두는 것이 좋겠다고 생각했다, 하지만 이론 공부도 물론 가져가긴 할 것이다. 무엇보다 오늘 여러가지 해보면서 나는 이 분야로 가는게 좋겠다는 확신이 들었고 코드를 짜는 과정에서 재미를 느꼈다. 특히 내가 모르던 내용들을 하나하나 배워가며 내가 짜는 코드들이 조금씩 조금씩 더 좋아지고 있다는 느낌을 받았고 더욱 보람차게 느껴졌다.
