느낀점
예비레포트를 쓰면서 이론이 상당히 부족하다고 판단되어 앞으로는 개인 공부뿐만 아니라 학교 공부도 가져가기 위해 노력할 것이고 금요일이 공강인만큼 금요일에 레포트 작성, 공학 수학 문제 풀기, 학교에서 학습한 내용 복습 등을 할 생각이다. 다행히 공학수학도 흥미 있게 느껴지고, 마이크로 프로세서 과목도 디지털 디자인과 초반 내용도 복습하고 이후에도 꽤나 겹치는 내용이 있어 문제 없이 학습할 수 있을 것 같다. 다만 전기회로 과목에 있어서는 아직 부족한 점이 많고 궁금한 점도 많아 집중적으로 학습할 필요가 있다고 생각했다. 테스트벤치 작성은 역시나 시간 가는줄 모르고 코딩할 수 있고 적성에 잘 맞는다고 생각한다.
