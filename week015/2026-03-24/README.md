느낀점
다행히 이번 학기 시작 전 디지털 디자인을 복습해 둔 덕분에 아직 배우지 않은 부분이 있더라도 어렵지 않게 과제를 풀 수 있었고 아직 기억 나는 부분도 많이 있었다. 또한 자바의 경우 SVA, C++의 접근 타입(protected, public, 
private, default) 및 생성자, this 등에 대해 아는 내용이 많아서 어렵지 않게 개념을 배울 수 있었고, 자바에만 있는 default 타입이 무엇인지와 자바에서의 패키지가 비슷한 기능을 하는 클래스들을 모아놓은 것이라는 것을 알게 
되었다. 또한 오버라이딩과는 다른 개념인 오버로딩이 같은 클래스가 이름이 같은 함수를 여러개 가지는 것을 의미하고 이들의 차이점을 위해 인자의 개수, 타입, 순서 등을 다르게 해야한다는 점 오버로딩을 통해 이름을 비교적 깔끔하게
맞출 수 있고 가독성 또한 좋아진다는 것을 알게 되었다. 마지막으로 우연인지는 모르겠으나 내가 따로 학습하는 내용들과 학교 수업들이 겹치는 부분이 상당히 많은 것 같아서 진짜 처음 접하는 개념은 많이 없어서 비교적 빠르게 배울
수 있어서 다행이라고 생각하고, 특히 자바 문법도 c++, 시스템 베릴로그를 합쳐 놓은 듯한 느낌이라 어렵지 않게 외울 수 있는 것 같다.
