느낀점
공학 수학 문제를 여러번 복습해보면서 어디에 어떤 식을 적용할 지를 더 생각해 볼 수 있었다. 오랫만에 수학 문제를 푸느라 이전에 수학을 풀던 감각이 많이 사라질 뻔 했으나 
적용할 곳에 대해 생각해보면서 다시 어느 정도 감을 잡을 수 있게 된 것이라고 생각한다. 내일은 하루 정도 쉬어갈 생각이다. 꽤나 오랜 시간동안 쉬지 않고 달려온 느낌이라 
내일은 잠도 충분히 자면서 그동안 하지 못했던 것들을 하면서 하루동안 휴식을 취할 생각이다. 물론 공부를 하지 않게 되더라도 이것이 그 다음날부터 다시 공부할 의지에 활기를 
불어 넣을 거라는 생각으로 하루동안 쉬고 다시 더 열심히 공부할 것이다.
