무엇보다 학교 학습 내용을 잊지 않기 위해 매주 토요일은 학교 공부 복습을 위해 사용할 필요가 있을 것 같다. 결과적으로 볼 때 이런 방식이 중간고사 기간동안도 더 도움이 될

툴 사용 경험을 쌓기 위해 노력해야 할 것 같고 뭐가 됐든 앞으로 더 열심히 학습해야겠다고 생각했다.
