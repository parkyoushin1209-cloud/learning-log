느낀점
확실히 UVM을 통해 많은 부분이 개션된 것 같다는 점을 느꼈고 단순히 학습만 하기보다 직접 코드를 작성해보면서 궁금한 내용들이 생기고 학습할 수 있었다.
RLC 회로를 통해 2계 ODE 풀이법을 점검하고 여러 문제를 풀어볼 수 있었으며 앞으로 남은 한 주동안 이번 챕터의 모든 문제 풀기를 목표로 잡을 생각이다.
op-amp 연결법 관련 영상을 보면서 op-amp의 정확한 연결법 확인과 Vcc, -Vcc 전압을 op-amp에 가해주는 법 short 되지 않게 연결하는 법 등을 배울 수 있었다.
