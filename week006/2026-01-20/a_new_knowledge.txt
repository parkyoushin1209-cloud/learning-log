AMBA AHB 프로토콜에서 버스 전송의 종류

IDLE: 버스가 사용되지 않음, 아무런 전송 없음

NONSEQ: 새로운 전송이 시작됨 (이전 전송과 관계 없음)

SEQ: 이전 전송에 이어지는 연속 전송

BUSY: 버스가 잠시 점유되었지만 데이터 전송은 없음

캡슐화 = 데이터와 그것을 처리하는 코드(기능)을 하나의 단위로 묶고, 외부에서 내부 주현을 직접 접근하지 못하게 숨기는 것
클로킹 블록은 TEST modport 기준 -> clk는 input으로 따로 안 씀 (포트리스트에)

master : request 구동 / slave: grant 구동

클로킹 블록에서 상승에지로 지연 설정시 => output posedge data_in 형식으로 작성
property 안에는 조건식이 들어감(concurrent assertion)
