const Date default_date(1970,1,1);
의미
-전역 상수 객체 하나를 정의 -프로그램 시작 시 한 번 생성 -프로그램 종료 시 파괴
특징
-함수 x, 객체 정의 -항상 같은 객체 -주소가 고정됨
장점
-가장 단순 -성능 오버헤드(일을 하는 데 직접 필요하지 않은데 추가로 드는 시간·메모리·연산 비용) 없음
단점
-초기화 순서 문제 (다른 전역 객체에서 사용 시)  -헤더에 두면 ODR(프로그램 전체에서 정의는 단 한 번만 존재해야 함) 위반 위험
언제
-진짜로 전역 상수 하나만 필요할 때

const Date default_date() {
    return Date(1970,1,1);
}
의미
-Date 객체를 반환하는 함수 -호출할 때마다 새 객체 생성
특징
-복사/이동 제거 보장  -호출마다 다른 객체(값은 같아도)
장점
-초기화 순서 문제 없음 -전역 객체 공유 안 함:안전
단점
-매 호출마다 생성 비용  -주소 동일성 보장x
언제
-값만 중요하고 객체 공유가 필요 없을 때

const Date& default_date() {
    static const Date dd(1970,1,1);
    return dd;
}
의미
-함수 내부 static 객체를 참조로 반환 -첫 호출 시 한 번만 생성 -이후 동일 객체 반환
특징
-lazy initialization -thread-safe(데이터 레이스 없음, 상태 일관성 보장, 동기화 보장) -전역 객체와 비슷하지만 더 안전
장점
-초기화 순서 문제 해결 -성능 좋음(한 번만 생성)  -주소 동일성 보장
단점
-참조 반환-> lifetime 이해 필요
언제
-싱글톤(하나만 존재해야 하는 객체를 전역처럼 쓰되, 안전하게 관리하는 방법) 같은 상수 객체 -여러 곳에서 같은 객체 공유
