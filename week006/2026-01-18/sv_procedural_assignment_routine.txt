sv에서는 반복문내에서 continue, break 사용이 가능하며 for문에서 int 정의 및 증가연산이 가능함
  case의 레이블을 범위로 지정 가능하며 inside 키워드와 [시작:끝]: ~~ 형태로 사용 가능하다

태스크, 함수, void 함수
    verilog에서 task는 시간관련 표현 사용이 가능하고 태스크 호출이 가능함, 반면 함수는 불가능하고 값을 무조건 반환함
    sv에서 void 함수는 값을 반환하지 않으며 function void name; 형식으로 표현 가능하다. 또한 시간 사용없는 태스크는 void함수로 대체하는 것이 좋다(다른 함수에서도 호출 가능)
    void'($fscanf(file,"%d",i)) 형태로 사용하면 함수를 호출해도 값을 반환하지 않을 수 있다.
태스크 함수
    -루틴 정의 또는 호출 시 인자가 없으면 () 생략 가능
   -begin-end를 task-endtask로만 써도 된다

루틴 인자 특징
    1. c스타일로 작성 가능하다 -> task my_task(output login [31:0] x, input logic y); 처럼
    2. 인자 방향 기본적으로 input logic으로 방향/타입으로 가지며 이 형식일 경우 name만 써도 가능하다, 하지만 버그를 찾기 힘드므로 그냥 전부 다 쓰는게 좋다.
    3. 향상된 인자 타입
      -verilog에서는 input, inout의 경우 루틴 시작시 지역 변수로 복사 output, inout은 루틴 종료시 복사였으며 스칼라값만 널을 수 있었다. = 배열은 불가능
      -system verilog에서는 ref를 사용해 배열을 참조할 수 있게 해줄 수 있으며 automatic을 함께 사용해야 한다.
    ++ref 
      3-1. const와 함께 사용할 경우 배열 값을 변경하지 않을 수 있다.
      3-2 배열을 전달 가능하게 해준다는 장점과 동시 실행문에서 이벤트 감지 리스트에 있는 변수가 태스크 도중 변하면 즉각적으로 반영해 실행문이 실행 될 수 있다.
      -> output으로만 선언 시 루틴이 끝나고 실행된다.
    4. 인자 기본값 function automatic void print_csm(const ref bit[31:0] a[], input bit [31:0] low = 0; input int high = -1) 처럼 등호를 사용해 기본값 지정 가능
      4-1 위의 함수는 print_csm(a) , (a,2,4), (a,1), (a,,2)와 같이 호출 가능하다.
    5. 이름으로 인자 전달 시 (a, .high(value)) 형식으로 전달 가능하다
    6. 흔한 코딩에러로 다음의 경우가 있다. task automatic sticky(ref int array[50]:1, input:2 int a, b) 1,2 가 둘 다 없을 경우 a,b의 방향을 모름, 2만 없으면 a,b도 array와 동일한 타입을 가짐
루틴의 반환
      1. 반환문 return을 사용 가능하며 c와 동일하다.
      2. 함수의 배열 반환 방법
      2-1 배열을 위한 타입을 선언하고 함수 선언부에서 사용하기 typedef int fixed_array5_t[5]; function fixed_array5_t[5]; 처럼
      2-2 참조(ref)를 이용한다.
지역 데이터 저장
        기본적으로 정적 공간에 저장함
      1. automatic storage 테스트벤치의 여러 곳에서 루틴을 호출할 경우 지역 변수가 스택에 저장되게 할 수 있어 두 루틴의 실행 과정에서 겹치는 부분이 사라딤
      2. 변수 초기화: 선언부에서 지역 변수 초기화를 같이 할 경우 문제가 발생할 수 있다. 이는 시뮬레이션 시작전 초기화가 진행되기 때문이다.
        2-1 이 문제를 방지하기 위해서 automatic, 선언부 따로 초기화문 따로 작성줄 수 있다.
타임 값  
      1. 타임 유닛, 정확성: `timmscale의 경우 한 번 정의하면 다음 파일에 영향을 줄 수 있으므로 끝나고 다시 기본값으로 1ns/1ns 처럼 리셋해줘야 한다. 또는 timeunit, timeprecision을 사용
      2. 타임 리터럴: timeunit, timeprecision, $time, $realtime, $timeformat(w,x,y,z) 등이 있고 timeformat의 w는 -9면 ns, -12면 ps/ x는 소숫점이하 자리수/ y는 시간값 출력후 
        출력할 문자열, z는 최소 필드 길이를 의미한다. => 이를 통해 시간을 적절하게 출력되도록 변경 가능하다.
      3.시간 변수
        3-1시간 값은 변수에 저장 및 계산, 지연에 사용 가능하다.
        3-2현재 scale, precision에 맞춰진다.
        3-3time은 64비트이므로 소숫점 1번째 자리에서 반올림, realtime은 소숫점 이하까지 정확히 표현해준다.
        -> 1ns/1ps에서 time 이 800ps면 1ns가 되고(0.8반올림) realtime은 0.8ns이 된다.
      4.$time, $realtime// 3번과 같이 계산한다.
