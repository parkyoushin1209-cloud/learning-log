클래스 인터페이스는 기본적으로 다음의 원칙을 지켜야 함
-인터페이스 완전하게 정의 
-인터페이스 최소화 => 문제 발생 시 확인해야할 함수 개수 줄어듬, 배우고 기억하기 쉬움, 잘 쓰이지 않는 불필요한 기능 구현에 시간 낭비 안 해도됨
-생성자 제공
-복사 제공(또는 복사 불가능하게)
-적절한 인자 검사 방법을 제공하는 타입 사용
-객체 상태를 변경하지 않는 멤버 함수 명시
-소멸자에서 모든 자원 해제

c++에서 직접적으로 지원하는 원칙
1. 인자 타입
{2005, 4, 5} => int int int 형인 경우 4월 5일인지 5월 4일인지 확실히 알 수 없음 int Month int처럼 확실히 하기

2. 복사 Date를 초기값으로 지정/ 다른 연산자의 오른쪽 피연산자로 사용
Date holiday{1978, Month::jul, 4};//초기화
holiday = Date{1978, Month::dec, 24};// 대입
cout << Date{1978, Month::dec, 24};//이처럼 리터럴로 사용도 가능

3.기본 생성자(인자가 없는 생성자)
public에 Date() 생성자 만들고 private에 int y가 아닌 int y{2000}c처럼 {}안에 기본값 지정 => 인클래스 초기값이라 함
생성자가 있을 경우 명시적으로 초기화하지 않으면 에러
const Date& default_date(){
static Date dd{200, Month::jan, 1};
return dd;
} //처럼 만들면 함수를 호출할 때마다 객체를 생성할 필요 없이 defaut_date().~~로 객체 1번만 사용하고 여러번 이용 가능
vector <Date> birthdays(10);으로 선언시 벡터 내 모든 값을 기본값으로 설정함

4.const멤버함수
class 내부 멤버 함수에 int year() const;처럼 선언 가능 또는 외부에 Date::day() const처럼 사용
const값을 멤버 함수에 넣었을 때 컴파일러는 그 함수가 값을 변경한다고 가정해버림 => 에러를 잡기 위해 const를 사용해 변경 가능/ 불가능 함수 구별함

5.멤버함수와 헬퍼함수
헬퍼함수는 멤버함수의 기능을 돕는 역할을 하는 함수로 가독성 향상, 중복 코드 제거, 테스트 난이도, 유지보수 난이도를 낮혀줌
