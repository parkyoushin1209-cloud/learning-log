사용자 정의 타입: 내장형 타입이 아닌 모든 타입
타입이 주는 정보로는 메모리 표현(객체에 필요한 데이터를 표현하는 방식을 알려줌), 연산(해당 객체에 적용할 수 있는 연산의 종류를 알려줌)이 있다.
class(struct는 public만 존재하는 class다)
  -프로그램 안에서 특정 개념을 직접적으로 표현하는 사용자 정의 타입
  -객체 표현 방법, 객체 생성 방법, 객체 사용 방법, 객체 소멸 방법을 명시한다.
  -내장형 타입과 사용자 정의 타입/함수로 이루어져있다.
  -클래스 밖에서 멤버 정의 시 class_name  :: member_name으로 한다.
  -인터페이스와 구현으로 이루어진다.
  - 멤버함수는 클래스 안에서도 정의할 수 있으며 이를 인라인 함수라 한다.
인터페이스: public:으로 표현 되면 사용자가 직접 접근 가능하다.
구현: private:으로 표현되면 클래스 외부에서 private은 인터페이스를 통해서만 접근 가능하다.
인라인 함수는 함수의 몸체가 짧을 때 유용하며 인라인 함수의 몸체를 변경할 경우 해당 클래스를 사용하는 코드도 다시 컴파일 되어야 한다.(밖에 있으면 클래스 선언 변경 시에만)
생성자: 해당 클래스와 이름이 같은 특수한 함수로 해당 클래스 객체 초기화(생성)시 사용한다.(생성자 포함 클래스 객체를 명시적으로 초기화 하지 않을 시 오류 발생)-Date holiday 등


열거형: 값(열거자)의 집합을 기호 상수로 정의//서로 연관돼있는 정수형 상수 집합이나 서로 구별되는 값 저장시 유용하다.
범위 제한 열거형 => enum class Month{ //class는 열거자가 해당 열거형의 유효 범위 안에 존재함을 나타내며 Month::jan으로 참조 가능하다.
  jan = 1, ~~~~ dec}; //1씩 증가 , 값 지정 x시 0부터
일반적인 열거형 enum Month{~~~~} 그냥 feb으로도 접근 가능 또는 int n = m으로도 가능 (Month -> int 는 가능이나 int -> Month는 불가능함)

연산자 오버로딩(기존 연산자에 사용자 정의 타입의 의미를 부여하는 것, 하나 이상의 사용자 정의 타입이 매개변수로 있어야 함)
type operator[] (매개변수) 형태 vector operator+ (const vector &, int); 
-주요 연산은 =, ==, !=, <, [], () 이다.

Month operator++(Month &m){
m = (m == dec)?jan:Month(int(m) + 1);
return m;
} 등으로 사용 가능
