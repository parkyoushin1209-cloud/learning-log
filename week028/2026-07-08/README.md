1. 형식 검증 진행 과정
RTL 보고 FSM 같은 상태 천이도가 만들어짐(이 때, 클록 기반이어야 하며 합성 가능해야 함) 그렇지 않은 경우 블랙박스 취급하며 출력을 자유 변수 취급함
이후 어써션 지시어를 통해 설정
검증할 범위가 매우 큰 경우
파티션, assume -> 실제로 발생은 가능하나 버리고 탐색하지 않음, restrict -> 아예 입력으로 안 나옴
이후 프로퍼티가 어겨지면 반례를 제공함

전역 클럭킹을 사용하기 위해 
global clocking idetifier clocking_evnet; endclocking으로 명시 가능

전역 클럭킹 과거 샘플된 값 함수는 액션 블록에 올 수 있음
전역 클럭킹 미래 샘플된 값 함수는 액션 블록에 올 수 없고, 다른 전역 클럭킹 미래 샘플된 값 함수에 중첩될 수 없으며, 시퀀스 매치 아이템이 있다면 못 쓰고 어써션이 이를 
가진다면 액션 블록은 다음 전역 클럭 틱에 실행될 것임
